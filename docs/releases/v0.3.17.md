Circuit now wears the SlotForge App Collection colours.

## What changed

- The app icon keeps its existing track shape and proportions, with a coral-red background and white track lines matching the SlotForge family.
- SVG, PNG and Windows ICO assets are updated together, including all seven Windows icon sizes.
- The README includes the collection brand logo, a right-aligned Circuit icon and links to Timing, Paddock, Telemetry, Decals and Livery.

This is a visual update. Track editing, saved workspace formats and Timing integration contracts are unchanged. All v0.3.16 reliability fixes are included.

## Verification

370 application/installer tests, 144 tests from the extracted Timing handoff and 15 integration fixtures passed. Icon geometry, colours, transparency and Windows icon sizes were checked. ZIP contents and SHA-256 checksums were verified.

## Install or update

1. Download **SlotForge-Circuit-v0.3.17-complete.zip** and extract the entire ZIP.
2. If your installed copy is running, click **Storage: disk** at the bottom right, choose **Stop local app**, then close that tab. If saving has failed, download a workspace backup first.
3. Run **Install Windows.cmd**, **Install macOS.command**, or `sh "Install Linux.sh"`, then start Circuit again. Re-running the installer updates its shortcut icon and keeps your saved Track Library and custom packs.

Circuit remains a browser-based app on Windows, macOS and Linux. The installer places the app and local helper on your computer. The complete ZIP is for normal use; the source and Timing handoff ZIPs are for developers. Each archive has a separate SHA-256 checksum file alongside the download. Personal workspaces are excluded.
