Circuit has a new Curve Studio icon: a flowing curve with editing handles, in SlotForge coral red and white.

## What changed

- The selected Curve Studio design replaces the oval app icon.
- The editor and every track-pack catalogue header share the same icon, including light, dark and custom themes.
- Browser favicons, the README icon, PNG and all seven Windows ICO sizes use the new design.
- Installed shortcuts that use Circuit's icon receive it when you run the installer again.

This is a visual update. Track editing, saved workspace formats and Timing integration contracts are unchanged.

## Verification

370 application/installer tests, 144 tests from the extracted Timing handoff and 15 integration fixtures passed. The icon matches the approved vector preview. Header image paths, PNG transparency, Windows icon sizes, ZIP contents and SHA-256 checksums were checked.

## Install or update

1. Download **SlotForge-Circuit-v0.3.18-complete.zip** and extract the entire ZIP.
2. If your installed copy is running, click **Storage: disk** at the bottom right, choose **Stop local app**, then close that tab. If saving has failed, download a workspace backup first.
3. Run **Install Windows.cmd**, **Install macOS.command**, or `sh "Install Linux.sh"`, then start Circuit again. Re-running the installer updates supported shortcut icons and keeps your saved Track Library and custom packs.

Circuit remains a browser-based app on Windows, macOS and Linux. The complete ZIP is for normal use; the source and Timing handoff ZIPs are for developers. Each archive has a separate SHA-256 checksum file. Personal workspaces are excluded.
