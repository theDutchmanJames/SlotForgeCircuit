Track files and piece packs are easier to find, share and manage.

## What changed

- **Import & Export** has separate **Tracks** and **Track Packs** choices, with prominent red import buttons and clearly labelled JSON downloads.
- Import or export a complete track from the builder, Track Library or Import & Export page. Track JSON still supports the SlotForge Timing integration.
- **Track Packs** now combines browsing and management: illustrated cards, search, All / Built-in / My packs filters, and Use in builder, Browse/Edit and Export actions. Import pack and Create pack are at the top.
- The former Plugins page is merged into Track Packs. Old bookmarks continue to work.
- Pack imports and creation no longer announce success after a failed save. Unsaved imported pieces remain available for recovery export.
- Oversized pack files are caught before downloading; unavailable or empty tracks keep their export controls disabled. Delayed export requests cannot interfere with a newer selection.
- Importing the wrong type of JSON now points you to the correct control.

The repository is now **theDutchmanJames/SlotForgeCircuit**. Existing installation folders, storage keys, saved-file formats and Timing integration contracts are unchanged. No data migration is required.

## Install or update

1. Download **SlotForge-Circuit-v0.3.19-complete.zip** and extract the entire ZIP.
2. If an installed copy is running, click **Storage: disk** in the bottom-right corner, choose **Stop local app**, then close its tab. If saving has failed, download a workspace backup first.
3. Run **Install Windows.cmd**, **Install macOS.command**, or `sh "Install Linux.sh"`, then start Circuit again. Your Track Library and custom packs are kept.

Circuit remains a browser-based app on Windows, macOS and Linux. This release was browser-tested on Windows; native macOS/Linux installation was not freshly audited. The source and Timing handoff ZIPs are also available, with SHA-256 checksums alongside all three archives. Personal workspaces are excluded.
