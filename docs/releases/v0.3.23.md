Plan with clearer drawings, correctly sized preview cars and more flexible routed sections.

## New tools and fixes

- **Visible SVG drawings:** black lines are now the default. Choose **SVG / DXF → SVG appearance** for fine coloured layers instead. Panel and stock-sheet SVGs use the same choice; paths, dimensions and DXF geometry are unchanged. Large drawings have enough page padding for their visible strokes.
- **Preview car sizes:** open **Tune profile → Car size** for 1:32, 1:24, 1:42 and 1:64 presets, or custom length and width in millimetres. Cars scale with the track and the preference is saved with the design. Presets use a generic 4.5 m × 1.8 m car, not a particular model; this is visual planning, not collision simulation.
- **Planning-only fold override:** near the bottom of the flowing-curve editor, enable **Override folds · planning only** to keep a section whose wood edge, slots or braid fold or cross. Editing, magnetic connections, saved packs, pictures and PDF piece counts remain available. These sections contribute no calculated racing lengths or materials; layouts containing them cannot run Live Preview or export SVG/DXF construction geometry until repaired and unchecked.
- **Consistent routed edge clearances:** new flowing presets match the profile preview, reflected straight previews show the correct margins, and newly attached routed straights align their margins with the adjoining section. Existing saved geometry is preserved.
- **Accurate timing status:** deleting the timing-line piece now shows that a piece must be chosen; Undo restores its status.

## SlotForge Timing integration

The `slotforge.layout` envelope remains version 1. Files containing planning-only override definitions explicitly require **1.0.0-draft.13**. Timing must adopt this contract deliberately; placed overrides cannot produce racing routes. Preview-car dimensions are optional workspace appearance metadata and do not change route identity or timing results. The shared runtime now includes **app/preview-car.js**. No SlotForge Timing repository changes are included.

## Install or update

1. Download **SlotForge-Circuit-v0.3.23-complete.zip** and extract the entire ZIP.
2. If an installed copy is running, click **Storage: disk** in the bottom-right corner, choose **Stop local app**, then close its tab. If saving has failed, download a workspace backup first.
3. Run **Install Windows.cmd**, **Install macOS.command**, or `sh "Install Linux.sh"`, then start Circuit again. Your Track Library and custom packs are kept.

Circuit runs in your browser on Windows, macOS and Linux. Complete app, source and Timing handoff ZIPs are supplied with SHA-256 checksums. Personal workspaces are excluded.
