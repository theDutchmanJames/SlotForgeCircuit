Circuit now saves installed workspaces in SQLite, with lighter library browsing and verified migration from existing JSON saves.

## What's new

- **Local SQLite storage:** tracks, the current drawing, packs and piece definitions are stored separately. Saves update changed records instead of rewriting the complete workspace. No database installation or account is needed.
- **Lighter libraries:** Track Library shows 24 tracks per page, searches saved names and caches previews. Opening or exporting a track loads that design. Custom pack contents are paged too.
- **More room for saved tracks:** the installed Track Library supports up to 5,000 tracks within a 200 MiB live-data limit. Custom packs retain their existing limits of 100 packs and 500 pieces overall.
- **Previous-save recovery:** open **Storage → Download previous save** to export the preceding saved workspace without changing the current one. Recovery history is bounded and lives in the same database; keep independent backups.
- **Reliability fixes:** corrected saved-version handling in Save dialogs, legacy browser preview revisions, deletion near the storage limit, migration conflicts after copying a data folder, and shutdown handling for queued saves.

## Update safely

1. In your current Circuit app, click **Storage: disk** in the bottom-right corner and choose **Download workspace backup**. Keep the JSON somewhere safe.
2. Choose **Stop local app**, then close the tab.
3. Download **SlotForge-Circuit-v0.3.24-complete.zip**, extract the entire ZIP and run its installer for your operating system.
4. On first launch, Circuit validates the old workspace, builds and verifies a separate SQLite database, then starts using it. Your tracks, custom packs, current drawing and saved identities are retained.

The original **workspace.json** and **backups/** files are kept unchanged. They represent the moment of migration; later saves go into **data/workspace.sqlite**. Do not launch an older version against that folder to roll back. If migration fails, keep the whole data folder and report the error. Circuit does not silently reset an invalid database.

Use **Storage → Download workspace backup** for portable backups of your latest work. Stop the local app before copying its entire data folder. Browser-only HTML use still saves in browser storage; use a workspace transfer to move those saves into the installed app.

## Compatibility and verification

Track JSON, workspace-transfer JSON and SlotForge Timing integration contracts are unchanged. SQLite is internal to Circuit; the Timing importer does not need a database change.

**468 app/installer tests, 167 extracted Timing handoff tests and 15 integration fixtures passed.** Isolated Edge checks covered migration, tracks and custom packs, paging, search, previews, JSON downloads, previous-save recovery and legacy browser-library upgrades. Personal saved data was not used for these checks. Native macOS/Linux execution remains unverified.

The **complete ZIP** is the normal user download. The **source ZIP** and **Timing integration handoff** are for developers. SHA-256 files are included for all three archives.
