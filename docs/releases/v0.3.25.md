Circuit now explains and performs the SQLite conversion on startup, with a clear completion screen and no manual import/export required for installed workspaces.

## What's new

- **Automatic upgrade screen:** when an installed JSON workspace needs conversion, **Upgrading your saved library** appears before conversion starts. Circuit checks, copies and verifies the saved data automatically.
- **Clear completion summary:** see how many tracks, custom packs and pieces were carried over, then choose **Continue to Circuit**. Your current drawing is retained too. The message stays dismissed after continuing and reloading.
- **Protected startup:** the editor and normal data operations stay blocked until verification succeeds. If conversion fails, the error remains visible and you can stop the helper without starting a replacement drawing.
- **Original files kept:** the previous `workspace.json` and backup folder remain untouched. New saves use SQLite. The README explains the process and recovery options.

Already using SQLite from v0.3.24? Your workspace opens normally; it is not converted again. The faster paged libraries, cached previews and **Storage → Download previous save** remain available.

## Install or update

1. As an extra precaution, use **Storage → Download workspace backup** and keep the JSON somewhere safe.
2. Choose **Storage → Stop local app**, then close the tab.
3. Download **SlotForge-Circuit-v0.3.25-complete.zip**, extract the entire ZIP, and run its installer.
4. If your installed workspace needs conversion, let Circuit finish the automatic startup upgrade, then click **Continue to Circuit**.

The conversion does not require users to export and re-import their installed workspace. Browser-only HTML saves are separate: use the existing workspace-transfer feature to move those into an installed copy. Keep independent backups; do not use an older app against the converted data folder to roll back.
