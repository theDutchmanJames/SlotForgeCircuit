Circuit gains tools for planning a layout, checking what you need to build it, and refining routed and FreeForm designs.

## New tools and where to find them

- **Builder → Planning tools:** measure distances and angles, include saved dimensions in PDFs, trace calibrated reference images, locate warnings, compare owned/used/missing pieces, and export a shopping CSV. The gap assistant previews connections using up to four fixed catalogue pieces. Curvature colours and car envelopes help inspect the layout.
- **Selection → Group, lock, replace & ramp:** keep groups together, lock finished sections, preview replacement pieces anchored at either end, and distribute ramp heights across a connected stretch. Click a **Parts list** row to find its pieces.
- **Builder → Colour by piece:** toggle colour coding for curve radii and straight lengths without changing the saved artwork. **Selection → Squeeze / Spread lanes** and the **Custom piece editor** can adjust plastic-piece slots and rails while keeping the road outline fixed.
- **FreeForm Drawing:** use **Stretch spacing / ramp** across several curves with a chosen peak and transition distance. **Smooth selected joins** previews aligned handles. **View & measure** contains curvature colours, car envelopes, reference images and measurements.
- **Planning tools → Convert routed layout to FreeForm:** preview the approximation before turning connected routed sections into one editable tabletop circuit. This makes the continuous FreeForm tools available to an existing routed layout.

Measurements, images, owned quantities, groups, locks and spacing profiles survive saves, library reopening and workspace backups. Owned quantities are per design. Tracing images stay out of PDF/CAD exports; printed dimensions are opt-in. Gap searches and car envelopes are bounded planning checks, not guarantees of physical fit. Construction Templates are not included.

## Install or update

Download **SlotForge-Circuit-v0.3.26-complete.zip**, extract it fully, and run the installer for your system. This remains one browser-based app for Windows, macOS and Linux.

For a running installed copy, open **Storage** in the bottom-right status bar, choose **Download workspace backup**, then **Stop local app** before updating. Run the new installer using the existing installation location; saved tracks and custom packs stay in their data folder. Older installed JSON workspaces retain the automatic, verified SQLite upgrade introduced in v0.3.25.

The source ZIP and Timing integration handoff are also provided, with SHA-256 checksums for all three archives. The main track JSON envelope stays at version 1. Plastic lane adjustments require Timing integration **draft.14**, and continuous FreeForm spacing requires **draft.15**; the updated shared runtime and specifications are included in the handoff.
