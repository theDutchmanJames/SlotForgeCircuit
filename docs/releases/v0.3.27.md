This small update brings Circuit's header and footer in line with the SlotForge app family and tidies the builder's right-hand panel.

## What's changed

- **Header:** the new Circuit SVG wordmark sits beside the Curve Studio app icon, with “Design it. Build it. Race it.” underneath. Navigation stays on one row.
- **Footer:** a small SlotForge collection logo sits at the bottom-right. Both logos use matching light and dark artwork with their original proportions.
- **Track-pack pages:** the same header is used throughout the built-in catalogues.
- **Track Builder → Track tools:** Planning tools now aligns with the other folders, with consistent width, margins and spacing.

## Verification

510 app/installer tests, 199 extracted Timing handoff tests and 15 integration fixtures passed. Browser checks covered both themes, all 10 catalogue pages, seven window widths, opening directly from disk, and the Planning tools folder expanded and collapsed. The supplied SVG artwork is unchanged.

## Install or update

Download **SlotForge-Circuit-v0.3.27-complete.zip**, extract it fully, and run the installer for your system. Circuit remains a browser-based app for Windows, macOS and Linux.

For a running installed copy, open **Storage** in the bottom-right status bar, choose **Download workspace backup**, then **Stop local app** before updating. Run the new installer using the existing installation location. Saved tracks and custom packs stay in their existing data folder.

Source and Timing integration handoff ZIPs are also included, with SHA-256 checksums. This update does not change storage formats or the Timing integration contract. Native macOS/Linux execution was not repeated for this visual update.
