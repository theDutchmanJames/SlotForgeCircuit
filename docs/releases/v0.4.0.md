Circuit is now a desktop app as well, with templates, lap times, a side view of track heights and a quicker, friendlier way of working.

## What's new

- **Desktop app for Windows, macOS and Linux:** choose the installer or the portable app. Circuit opens in its own window. Installed copies open your existing Track Library straight away; the portable app keeps everything in a *SlotForge Circuit Data* folder beside it.
- **Templates:** *File → Start from a template…* builds a compact oval, long oval, club rectangle or wide oval from your track system's standard straight and curves, so every template closes exactly. A **figure eight with a bridge** starts in FreeForm.
- **Lap times:** *Tune profile → Lap times* shows a time and average speed for every lane, and how far each lane is behind the fastest. They use the same speed plan as Live Preview, so set the profile to your cars' speeds for realistic times.
- **Side view of heights:** *Heights & bridges* (and FreeForm *Checks*) shows the height along the lap, the highest point and the steepest climb. Climbs over 10% are flagged.
- **Update notice:** the desktop app tells you when a newer version is published, with *Download* (the release page in your browser) or *Not now*. It checks at most twice a day, sends nothing about you or your tracks, and never installs anything by itself. *Settings → Updates* has *Check now* and turns the automatic check off.
- **Inches and feet:** *Settings → Measurement units → Imperial* shows lengths, footprints, speeds and the PDF report in inches and feet.
- **Files on the desktop:** system Open and Save dialogs that remember your folder, a recent-files list in the File menu, and double-click a **.slotforge** track file to open it. *Track JSON for SlotForge Timing* (.slotforge.json) is still offered when saving.

## Easier to use

- **Welcome screen** on first start, and a **?** help button. Press **?** for all keyboard shortcuts; Ctrl+N and Ctrl+O are new.
- **Right-click** a piece to rotate, mirror, duplicate, add borders, set heights, lock or delete it.
- **File menu:** the builder's top bar is now *Save to Library* plus **File ▾**.
- **Routed Wood** keeps the routing profile in a side panel beside its preview, materials and checks.
- **Tidier navigation:** editing your own pack now lives under Track Packs, and each import or export has one clear home.
- **Shorter help texts** with a *More* link, and clearer empty states for the Track Library and new FreeForm drawings.

## Faster

- **Zooming, panning and dragging** no longer redraw the whole track: a zoom step went from about 14 ms to 2 ms and each drag frame from about 15 ms to under 2 ms on a 190-piece layout, so large layouts stay smooth.
- **Adding pieces** is about twice as fast on large layouts, because connections are worked out once per change and only changed pieces are redrawn.
- **Saving** happens once you pause editing instead of after every change: 30 quick edits now write one save instead of 30. Quitting, backups and closing the window still save a waiting change first.
- **Starting** loads half as much: the PDF library (2 MB) now loads the first time you make a PDF, and the start-up save of an unchanged track is gone.

## Fixed

- The track could be off-screen when Circuit started on another page or in a small window.
- The local server refused every file when Circuit ran from a Windows short path (such as `C:\Users\LONGNA~1\…`).

## Verification

57 unit test files and 28 interface tests passed, the interface tests clicking through the real app on every build. The Windows installer was installed, started, associated with .slotforge files and uninstalled again cleanly; the portable app was started from an empty folder. macOS and Linux builds were not run for this release.

## Install or update

Download the installer or portable app for your system. Before updating, open **Storage** in the bottom-right corner and choose **Download workspace backup**. If the browser edition is still running, choose **Stop local app** there first. Saved tracks and custom packs stay in their existing data folder; this update does not change storage formats or the Timing integration contract.
