A big update: a new look throughout the app, a better update window, faster storage, and many fixes found by a new round of testing.

## What's new

- **New look throughout:** a redesigned Track Library, Print Shop, Track Packs, Settings, Routed Wood, Builder side panels, FreeForm guide and dialogs.
- **Better updates:** the update window shows what's new and downloads the right file into your Downloads folder.
- **Faster:** library pages, pictures and saves are quicker, and track packs load in one step.
- **Pack galleries in their own window:** Open the gallery no longer replaces the app.
- **Portable app:** opening it twice, or from a FAT/exFAT USB stick, now works.
- **Safer after a crash:** Circuit starts normally again and nothing is half-saved.

## Fixes

- Typing a huge number of lanes in Routed Wood no longer freezes and crashes the page.
- Routed Wood's Apply now opens the folded group that holds a bad value, instead of doing nothing.
- A huge owned quantity in the Parts list is kept to 100,000 instead of causing an error.
- The first click on a top navigation link no longer reloads the whole app.
- After a crash, Circuit no longer refuses to start with a "window is writing" message.
- A crash during the move from the old JSON workspace no longer leaves a full copy of the tracks behind.
- A damaged workspace file now shows the advice to restore a backup.
- On Linux, Circuit no longer mistakes a running copy of itself for one that had closed, so two copies can't save to the same folder at once.
- On Linux, recent files that differ only in upper and lower case are kept apart, because Linux treats them as different files.
- CAD exports for SlotForge Foundry now carry routed profiles, road width and spot heights.
- Undo no longer stores a copy of the reference picture for every step.

## Verification

60 unit test files pass on Windows and Linux, and 48 interface tests clicking through the real app pass on Windows. New this release:

- **Random saves:** about 4,700 random library actions, with every view checked against the others after each step.
- **Crash tests:** 40 kills in the middle of saves and 20 in the middle of the old-workspace move. Nothing was lost or half-saved.
- **Random-click run:** a full hour on a copy of a real library plus 60 sample tracks: 15,437 actions with no freezes or crashes.
- **Coverage map:** the code that opens `.slotforge` files went from 41% to 100% tested.

Circuit is not code-signed: on Windows choose **More info → Run anyway**, or right-click the downloaded file → **Properties** → **Unblock**; on macOS right-click the app and choose **Open** the first time; on Linux mark the AppImage as executable (`chmod +x`). The SHA256SUMS files list each download's checksum.

Install over 0.4.1 as before: your saved tracks and packs stay where they are. Storage formats and the SlotForge Timing integration are unchanged.
